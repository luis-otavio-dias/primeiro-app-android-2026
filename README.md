# Primeiro App Android

Aplicativo de exemplo feito em Kotlin para praticar campos de formulário no Android.

## Executar no Android Studio

1. Abra o Android Studio e selecione **Open**.
2. Escolha a pasta deste projeto e aguarde a sincronização do Gradle.
3. Inicie um emulador ou conecte um dispositivo Android com depuração USB ativada.
4. Selecione a configuração `app` e clique em **Run** (▶).

O projeto usa `minSdk 24` e `compileSdk 36`.

## Exercício

A tela contém campos para e-mail e senha e o botão **Entrar**. Ao tocar no botão, o app exibe um Toast com os valores informados nos dois campos, sem validação.
